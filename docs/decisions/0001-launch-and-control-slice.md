The software control is the hand-checkable identity `counter(t) = t` at integer seconds 0 through 4. It is dimensionless bookkeeping with a known exact answer, **not a physiological model, an adopted benchmark or a numerical solver**. It exists to falsify contract, comparison and recovery defects while source admission proceeds. No model-selection conclusion depends on this control.

The supported study is fixed and admits no parameter variations. Every quantity has an exact unit and semantic kind. Unknown fields, duplicate JSON keys, incompatible units, unsupported model/conditions, Boolean numbers, nonfinite values and excessive input are rejected. Registry membership comes from packaged reviewed code; an input document cannot authorize its own adapter, rights or acceptance rule.

The control adapter writes only raw CSV and diagnostics in its attempt directory. The parent evaluator owns the independently declared reference values, exact control comparison and output completeness rules. These references and criteria are copied into the attempt before execution. A future physiological contract must supply source-grounded criteria; exact equality for this integer control must never become a physiology tolerance.

Each invocation reserves a new UUID attempt directory. A completed bundle is finalized by an atomic same-filesystem directory rename after file flushes. A crash leaves a visible `.partial` attempt. Listing/inspection never confuses that directory with a completed result. Retrying creates a new attempt; it never overwrites a previous bundle or erases failed evidence. Failures have no favorable agreement result. Process time, address-space, file size and diagnostic output are bounded on the verified Linux environment. These hygiene measures are **not a sandbox**; third-party adapters, generated plugins and protected confirmation remain disabled.
