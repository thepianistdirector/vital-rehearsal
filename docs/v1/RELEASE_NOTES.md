# Vital Rehearsal 1.0.0rc4 — local release candidate

Prepared locally, 8 September 2026. Not publicly released, submitted, peer reviewed or human validated.

Researchers can now run an exact licensed public respiratory software exposure through a sealed experiment, inspect actual trajectories, compare another numerical algorithm, retain source diagnostics, reproduce the original runner and export complete evidence. The original exact-integer control remains available for software verification. Deterministic synthetic FCFS scheduling supports independent matched process studies; no clinical event coupling is admitted.

The scope is deliberately narrow: Ben-Tal 2006 combination CellML exposure b503501533abcf0e70786789f08cb902 at revision 2e0e7ccc682bbf326829b3d78e3137ebdf8dbca0, default initial state, up to ten seconds, bounded solver choices and a numerical R±10% neighbourhood. A measured pressure-derivative inconsistency is preserved and displayed. This is neither a validated physiology engine nor a reproduction of a specific paper figure.

## Included

- CLI example → edit → seal → validate → run → inspect/export; immutable study schema `vital-research/1`.
- Radau, BDF, RK45, DOP853 and source-VODE integration, exact source, state units, solver/runtime/build cards and CSV/JSON/HTML outputs.
- Deterministic nonpreemptive FCFS multi-server synthetic scheduling. Jobs sort by arrival then ASCII ID; servers by earliest prior finish then ID.
- Failed, timed-out, gracefully cancelled and hard-interrupted evidence retention. Recovery creates a new attempt; it never overwrites or silently resumes a partial state.
- Offline CPython 3.12 Linux x86_64 dependencies with hash-locked wheels and notices, source, examples, tests and first-run guide.
- Three frozen research packages, independent automated skeptical reproduction, publication figures, launch copy and an updated canonical plan export.

## Compatibility and limits

Original software-control command/schema behavior remains separate. Research schema v1 and model source hash reject unsupported or modified experiments. Source archives and manifests establish reproducibility and change detection, not signatures or adversarial isolation. No arbitrary user model code is executed. One worker uses a scrubbed environment, one BLAS thread, bounded CPU/address space/file sizes and a finite wall timeout. No multi-host or hostile-evaluator isolation claim is made.

The original research used the retained rc1 investigation archive, SHA256 `bc4043aa8c99b16354dd08aaf595c09a65a7b070be981ba435ba4c41210b2db2`. Selected rc4 reruns produced identical numerical files. Earlier rc2/rc3 intermediate builds remain local historical attempts; rc2 had a filename/internal-version mismatch and is not a release artifact. They do not replace frozen confirmation.

Qualified model interpretation review, independent human first-run reproduction, public release approval and authorized Tanduna plan/publication readback remain open. The larger whole-body, multi-model, clinical coupling and broad-platform roadmap is preserved without being represented as implemented.
