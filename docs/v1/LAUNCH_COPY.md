# English launch copy — draft, not posted

**Vital Rehearsal: inspect the model, run the experiment, keep the evidence.**

Vital Rehearsal's v1.0 release candidate turns a licensed public respiratory software exposure and wholly synthetic process scenarios into reproducible research bundles. Researchers can inspect model limits and units, seal an experiment, run its numerical equations, compare solver outputs, and export trajectories, diagnostics and the exact source needed to rerun it.

Three accompanying methodological studies show why these controls matter. Independent solver agreement reproduced an internal pressure-derivative inconsistency in the source exposure. Tight solver controls separated local resistance sensitivity from numerical disagreement. Matched synthetic queues showed how the same one-second service increment can disappear into idle time or accumulate across a busy horizon.

The package makes those boundaries visible: no patient records, clinical advice, validated physiological predictions, therapeutic benefits or care-to-physiology coupling. These are reproducible computational and engineering drafts, not peer-reviewed or human-validated clinical findings. Qualified interpretation review and an external researcher's first run are still needed.

Explore the [repository](https://github.com/thepianistdirector/vital-rehearsal) and the [Vital Rehearsal Tanduna project](https://tanduna.com/projects/vital-rehearsal). We welcome qualified review of the exact source semantics, independent reproduction on the documented Linux/Python environment, rights-cleared reference evidence, and accessibility testing. A useful issue includes the sealed study, exact build, expected/actual behavior and retained failed evidence—never patient records.
