Vital Rehearsal **1.0.0rc4** is an explicitly unreviewed research prerelease. It provides a bounded, reproducible numerical workbench for an exact licensed respiratory software exposure and a separate synthetic care-process scheduler.

## Get started

Download `vital-rehearsal-1.0.0rc4-linux-x86_64-py312.tar.gz` and `SHA256SUMS`, verify the checksum, extract the archive, and follow `docs/v1/FIRST_RUN.md`. Supported: Linux x86_64, CPython 3.12. Offline hash-locked NumPy/SciPy wheels, optional plotting dependencies, full application/model source, notices, examples, tests and three research packages are included. No developer credentials are needed.

The smaller `.pyz` requires the pinned dependencies separately. The verification archive contains the final extracted-package checks and retained reruns.

## What works

Inspect applicability and units → create/edit/seal a supported experiment → run the real numerical source model → inspect trajectories, source-default solver comparison and diagnostics → reproduce/export the full evidence bundle. Each attempt retains its exact source archive; timeout, numerical failure and interruption evidence is preserved, and recovery creates a new attempt.

The original software control remains separate. Synthetic nonpreemptive FCFS scheduling supports matched baseline/service-delay studies, with no physiology coupling.

## Three bounded research drafts

- **Source reproduction and semantic audit:** numerical agreement coexists with an upstream pressure-derivative inconsistency, measured independently at up to 7.406520732 mmHg/s.
- **Numerical and local parameter robustness:** tight cross-algorithm controls separate numerical disagreement from R±10% equation sensitivity; no physiological population uncertainty is inferred.
- **Synthetic scheduling:** matched finite queues show that a one-second service increment can be absorbed by idle time, accumulate across a busy horizon, or produce bounded within-batch delays.

The archive includes frozen protocols, all 50 original experiment bundles, executable studies, figures, manuscripts and a separate automated skeptical review. Eight reviewer reruns reproduced selected outputs; a fresh offline installation of this exact archive passed 65 tests and reran all three studies plus the eight reviewer cases. Same host only: these are not external human or separate-machine observations.

## Essential limitations and review status

The admitted source is the unchanged Ben-Tal 2006 **CellML combination exposure**, revision `2e0e7ccc682bbf326829b3d78e3137ebdf8dbca0`, under CC BY 3.0. It explicitly does not equal any one model in the original paper. The source derivative discrepancy remains unchanged and visible. XML normalization accommodates unusual E/z units; their dimensional invalidity is not established.

The VODE comparator shares the model equations. No independent empirical trajectory, validated physiological prediction, patient record, clinical advice, therapeutic benefit, or scientifically reviewed care-to-physiology event mapping is included. No novelty or peer-review claim is made.

**Qualified human interpretation review and an external researcher's first run remain pending. This prerelease does not complete final v1.0 acceptance.** Native Tanduna draft submission, review, acceptance and publication are tracked separately from this GitHub release.
